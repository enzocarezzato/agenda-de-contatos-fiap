# Agenda de Contatos (FIAP)

Projeto final da disciplina de Lógica de Programação da FIAP. Uma agenda de contatos resolvida em três etapas, para mostrar a mesma lógica em linguagens diferentes.

## Estrutura

- `01-pseudocodigo`: planejamento da solução em pseudocódigo
- `02-python`: implementação em Python
- `03-java`: implementação em Java

## Funcionalidades

- Cadastro de contatos
- Busca de contatos
- Exibição da lista de contatos

## Como executar

**Python**
```
cd 02-python
python nome_do_arquivo.py
```

**Java**
```
cd 03-java
javac NomeDoArquivo.java
java NomeDoArquivo
```

## O que aprendi

- Estruturação de lógica antes de programar, com pseudocódigo
- Uso de listas, funções e condicionais
- Diferenças de sintaxe entre Python e Java
